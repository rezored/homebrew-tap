# rezored/homebrew-tap

Homebrew tap for [Cubicle Crew](https://github.com/rezored/cubicle-crew) – your Claude Code agents as pixel-art coworkers in a tiny office.

```bash
brew install --cask rezored/tap/cubicle-crew
```

Updates: `brew upgrade --cask cubicle-crew`. Uninstall: `brew uninstall --cask cubicle-crew` (add `--zap` to also remove the saved office in `~/.pixel-office`).

The app is not signed with an Apple Developer ID – it is a free project – so the cask removes the macOS quarantine flag after installing. Nothing else is changed.
